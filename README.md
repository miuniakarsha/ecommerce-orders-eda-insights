\# E-Commerce Orders Exploratory Data Analysis: Sales, Product \& Customer Insights



\## Project Overview



This project is DecodeLabs Data Analytics Project 2.  

The purpose of this project is to perform Exploratory Data Analysis (EDA) on an e-commerce retail orders dataset.



Project 1 focused on data cleaning and reliability.  

Project 2 focuses on discovering patterns, trends, outliers, relationships, and business insights from the cleaned dataset.



\## Main Business Question



What patterns, trends, outliers, and business insights can be discovered from the retail orders data?



\## Project Objectives



\- Verify the cleaned dataset from Project 1

\- Calculate descriptive statistics

\- Analyze distributions

\- Detect outliers using IQR and Z-score

\- Analyze sales trends over time

\- Explore correlations between numerical variables

\- Analyze product, payment method, coupon, referral source, and order status patterns

\- Build a Power BI dashboard focused on EDA insights

\- Summarize business insights and recommendations
